# Faltas-FP
App web para estudiantes de FP que controla el límite de faltas (ej. 15%). Permite configurar asignaturas y horas   totales, sumar/restar faltas y visualizar la disponibilidad mediante barras de progreso con alertas de color. Incluye   un resumen global de riesgo, gestión dinámica de materias (añadir/borrar/editar) y persistencia de datos local. 🚀
