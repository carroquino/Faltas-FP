 🎓 Control de Faltas FP

 Lleva el control de tus faltas y evita perder la evaluación continua.

  Esta aplicación te permite saber exactamente cuántas horas has faltado en cada módulo y cuántas te quedan disponibles
  antes de alcanzar el límite permitido por tu centro (normalmente el 15%).

  🚀 Cómo empezar

  1. Abre la aplicación: Abre el archivo index.html en cualquier navegador de tu móvil o PC.
  2. Configuración Inicial: La primera vez que entres, la app te pedirá:
     - Tus asignaturas: Escríbelas separadas por comas (ej: IPE1, SOM, Redes, Inglés...).
     - % de límite: Indica el porcentaje de faltas permitido en tu centro (por defecto es 15%).
  3. ¡Listo!: Ahora verás el panel principal con todas tus materias.

  🛠️ Funciones Principales

  📋 Gestión de Módulos

  - Suma de faltas: Usa el botón +1 hora para añadir una falta o el botón + Varias si quieres sumar varias horas de una
    vez.
  - Corregir errores: Si te has equivocado, usa el botón − para restar una hora.
  - Horas Totales: Si el número de horas del módulo no es correcto, puedes editarlo directamente en el cuadro Total h de
    cada tarjeta.

  📊 Control Visual

  - Barras de progreso: Verás una barra que se llena a medida que faltas.
  - Alertas de color:
    - 🟢 Verde: Tienes margen suficiente.
    - 🟡 Ámbar: Estás llegando al límite (80% o más). ¡Cuidado!
    - 🔴 Rojo: Has superado el límite permitido.

  ⚙️ Ajustes Avanzados

  - Añadir/Borrar: Puedes añadir nuevas materias con el botón + Añadir Materia o eliminar las que ya no necesites con el
    icono de la papelera 🗑️.
  - Editar nombre: Si escribiste mal una asignatura, pulsa el icono del lápiz ✏️ para cambiar el nombre.
  - Configuración Global: En el botón de ⚙️ Configuración puedes cambiar el % de límite del centro para todo el curso o
    borrar todos los datos para empezar de cero.

  📱 Tips para el Móvil

  Para tener la app a mano como si fuera una aplicación instalada:
  1. Abre el enlace en el navegador de tu móvil.
  2. Pulsa en el menú de opciones del navegador (tres puntos o flecha de compartir).
  3. Selecciona "Añadir a pantalla de inicio".

  Tus datos se guardan de forma local en tu navegador, por lo que son privados y no se envían a ningún servidor.
